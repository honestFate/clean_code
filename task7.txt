3.1. Методы-фабрики

1) OrderedList — task7/task7.py
было:
    OrderedList(True)
    OrderedList(False)
стало:
    class OrderedList:
        def __init__(self, ascending: bool) -> None: ...

        @classmethod
        def ascending(cls) -> "OrderedList":
            return cls(True)

        @classmethod
        def descending(cls) -> "OrderedList":
            return cls(False)

    OrderedList.descending()

2) SaltedHashTable — task8/task8_2.py
было:
    SaltedHashTable(17, 3)
    SaltedHashTable(17, 3, 12345)
стало:
    SaltedHashTable.with_random_salt(table_size=17, probe_step=3)
    SaltedHashTable.with_fixed_salt(table_size=17, probe_step=3, salt_value=12345)

3) результат операции бота — tasks_bot, app/database/database.py
было:
    return {'status': True, 'text': r.json()}
    return {'status': False, 'text': "Вы не зарегистрированы в системе"}
    return {'status': False, 'message': "Техническая ошибка. Обратитесь в тех.поддержку"}
стало:
    @dataclass(frozen=True)
    class BotReply:
        is_success: bool
        text: str

        @classmethod
        def success(cls, text: str) -> "BotReply": ...

        @classmethod
        def failure(cls, text: str) -> "BotReply": ...

        @classmethod
        def technical_error(cls) -> "BotReply":
            return cls.failure(TECHNICAL_ERROR_TEXT)

    return BotReply.failure(NOT_REGISTERED_TEXT)
// словари с True/False в первом поле собирались вручную в каждой
// функции, в put_register ключ текста назывался message вместо text;
// фабрики задают форму ответа в одном месте
